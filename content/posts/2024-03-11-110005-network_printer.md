## UVA printing systems {#uva-printing-systems}

you need a local printing stack (CUPS) configured to talk to the UVA print servers or queues, possibly via LPD or IPP, with authentication (your [University of Virginia (UVA)]({{< relref "2025-04-11-013919-university_of_virginia.md" >}}) credentials), and have a correct PPD or driver.


## What you need on Arch Linux {#what-you-need-on-arch-linux}

First, install and enable the printing stack on your system:

```bash
sudo pacman -S cups cups-filters ghostscript gutenprint  # plus any printer-specific driver packages you need
```

You might also want GUI tools:

```bash
sudo pacman -S system-config-printer
```

Enable the CUPS service:

```bash
sudo systemctl enable --now cups.service
```


## Access <http://localhost:631/admin> {#access-http-localhost-631-admin}

-   Administration → Add Printer
-   Choose “LPD/LPR host or printer” (or “LPD/LPR” / “Network Printer” depending on interface)
-   For the Device URI, enter the URI you found above
    -   lpd://printserver.cs.virginia.edu/printer018
-   Choose the PPD (driver) – either from the CUPS database or upload a PPD file if CS provides one
-   Name &amp; describe the printer (e.g. cs-ricehall-bw)
-   Set defaults (paper size, duplex, black &amp; white vs color, etc.)
