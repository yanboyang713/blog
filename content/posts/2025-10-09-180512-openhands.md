## Running OpenHands Locally {#running-openhands-locally}


### Install [uv]({{< relref "2025-04-19-021805-uv.md" >}}) {#install-uv--2025-04-19-021805-uv-dot-md}


### Launch OpenHands {#launch-openhands}

```bash
# Launch the GUI server
uvx --python 3.12 --from openhands-ai openhands serve

# Or launch the CLI
uvx --python 3.12 --from openhands-ai openhands
```

You'll find OpenHands running at <http://localhost:3000> (for GUI mode)!
