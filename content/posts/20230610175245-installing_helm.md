[Helm]({{< relref "20230604152949-helm.md" >}}) runs as a command-line interface (CLI) and is typically installed on your notebook.

You have several options for installing Helm:


## Using the Binary Releases {#using-the-binary-releases}

<https://helm.sh/docs/intro/install/#from-the-binary-releases>

[Download the release](https://github.com/kubernetes/helm/releases), including the binary.


## Through Package Managers {#through-package-managers}


### [Homebrew]({{< relref "20230610193812-homebrew.md" >}}) ([macOS]({{< relref "20230610194125-macos.md" >}})) {#homebrew--20230610193812-homebrew-dot-md----macos-20230610194125-macos-dot-md}

Members of the Helm community have contributed a Helm formula build to Homebrew. This formula is generally up to date.

```bash
brew install helm
```

(Note: There is also a formula for [emacs-helm]({{< relref "20230610194458-emacs_helm.md" >}}), which is a different project.)


## Using [Script](https://helm.sh/docs/intro/install/#from-script) {#using-script}

Use an installer script:

```bash
curl https://raw.githubusercontent.com/kubernetes/helm/master/scripts/get > get_helm.sh
```

For more information about [installing Helm](https://docs.helm.sh/using_helm/#installing-helm), see Installing Helm in the Helm documentation.
