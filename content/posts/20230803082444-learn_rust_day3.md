## Welcome to Day 3 {#welcome-to-day-3}

Today, we will cover some more advanced topics of Rust:

-   [Traits]({{< relref "20230805232808-rust_traits.md" >}}): deriving traits, default methods, and important standard library traits.
-   [Generics]({{< relref "20230803082907-rust_generics.md" >}}): generic data types, generic methods, monomorphization, and trait objects.
-   [Error Handling]({{< relref "20230806021510-rust_error_handling.md" >}}): panics, Result, and the try operator ?.
-   [Testing]({{< relref "20230806032731-rust_testing.md" >}}): unit tests, documentation tests, and integration tests.
-   Unsafe Rust: raw pointers, static variables, unsafe functions, and extern functions.
