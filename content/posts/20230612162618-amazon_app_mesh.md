(On 28, Nov 2018), Amazon, the largest cloud vendor, also announced [AWS]({{< relref "20230314144515-aws.md" >}}) App Mesh, a service mesh solution for microservices on AWS. The best and worst part of AWS App Mesh is its native compatibility with Amazon Web Services. This might guarantee a minimum integration effort from users and probably provides best-effort performance, but at the same time, it might also result in vendor lock-in issues and inapplicability to hybrid cloud environments.
