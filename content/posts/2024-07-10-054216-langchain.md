## What is LangChain? {#what-is-langchain}

LangChain is a powerful framework for building applications with LLMs. It provides tools to manage memory, chaining, retrieval, and processing of large text data.


## Key Features of LangChain {#key-features-of-langchain}

-   Text Chunking &amp; Splitting — Helps break large documents into smaller chunks for LLMs.
-   Memory Management — Allows models to remember context across multiple interactions.
-   [Retrieval Augmented Generation (RAG)]({{< relref "2023-12-06-164642-retrieval_augmented_generation_rag.md" >}}) — Fetches relevant information before generating responses.
-   Multi-Model Compatibility — Works with [OpenAI API]({{< relref "2023-10-23-193127-openai_api.md" >}}), [Hugging Face]({{< relref "2025-11-05-002206-hugging_face.md" >}}), [Ollama]({{< relref "2025-04-14-230239-ollama.md" >}}), and more.
