## What Wayland is {#what-wayland-is}

-   Wayland is a [display server protocol]({{< relref "20230721000134-display_server_protocol.md" >}}): a language apps (clients) use to talk to a compositor (the display server). In Wayland, the compositor is the display server.
-   The protocol is minimal by design; lots of features come via extensions (e.g., xdg-shell, layer-shell).


## How it differs from [Xorg/X11]({{< relref "20230721000322-xorg.md" >}}) {#how-it-differs-from-xorg-x11--20230721000322-xorg-dot-md}

-   Direct model: the compositor reads input and renders windows; apps report “what changed” (damage) to it—no middleman X server with forwarding and reparenting. This cuts complexity and can reduce latency/tearing.

wayland.freedesktop.org

-   Security model: by default, one app can’t snoop on another’s input/screen; things like screen-sharing go through portals (user-mediated APIs).


## Who ships it {#who-ships-it}

-   [Hyprland]({{< relref "20230729224246-hyprland.md" >}}) is a modern, dynamic-tiling Wayland compositor with lots of recent-protocol support.
