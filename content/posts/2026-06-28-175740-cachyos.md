CachyOS is a Linux distribution based on [Arch Linux]({{< relref "20230220222636-arch_linux.md" >}}). It focuses on speed and security optimisations - the default Linux kernel is heavily optimised using the BORE (Burst-Oriented Response Enhancer) scheduler, while the desktop packages are compiled with LTO, x86-64-v3 and x86-64-v4, Zen 4 optimization, security flags and performance improvements. The available desktop environments, window managers and [Wayland]({{< relref "20230721000055-wayland.md" >}}) compositors include bspwm, Budgie, Cinnamon, COSMIC, GNOME, [Hyprland]({{< relref "20230729224246-hyprland.md" >}}), i3, KDE Plasma, LXDE, LXQt, MATE, Niri, Openbox, Qtile, Sway, UKUI, Wayfire and Xfce. CachyOS also ships with both graphical and command-line system installers.
