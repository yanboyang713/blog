[nat]({{< relref "2023-11-07-011649-nat.md" >}})

A reverse proxy server is a type of proxy server that typically sits behind the [firewall]({{< relref "20230404162828-firewall.md" >}}) in a private network and directs client requests to the appropriate backend server. A reverse proxy provides an additional level of abstraction and control to ensure the smooth flow of network traffic between clients and servers.
