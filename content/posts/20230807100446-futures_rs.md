futures-rs is a library providing the foundations for asynchronous programming in [Rust]({{< relref "20230220230005-rust.md" >}}). It includes key trait definitions like Stream, as well as utilities like join!, select!, and various futures combinator methods which enable expressive asynchronous control flow.
