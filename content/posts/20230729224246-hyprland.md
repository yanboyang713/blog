Hyprland is a wlroots-based tiling [Wayland]({{< relref "20230721000055-wayland.md" >}}) compositor written in C++. Noteworthy features of Hyprland include dynamic tiling, tabbed windows, a clean and readable C++ code-base, and a custom renderer that provides window animations, rounded corners, and Dual-Kawase Blur on transparent windows. General usage and configuration is thoroughly documented at Hyprland wiki.


## Installation {#installation}


### Packages {#packages}

```bash
yay -S hyprland-git
```


### CMake (recommended) {#cmake--recommended}

```bash
git clone --recursive https://github.com/hyprwm/Hyprland
cd Hyprland
sudo make install
```

### Setting [display manager]({{< relref "20230729224458-display_manager.md" >}}) [SDDM]({{< relref "20230729224649-sddm.md" >}}) {#setting-display-manager--20230729224458-display-manager-dot-md--sddm--20230729224649-sddm-dot-md}

Available session types can be found in _usr/share/xsessions_ for X and in _usr/share/wayland-sessions_ for Wayland.
Create file hyprland.desktop

```file
[Desktop Entry]
Name=Hyprland
Comment=An intelligent dynamic tiling Wayland compositor
Exec=Hyprland
Type=Application
```
