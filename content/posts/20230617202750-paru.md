Paru is your standard pacman wrapping AUR helper with lots of features and minimal interaction for [Arch Linux]({{< relref "20230220222636-arch_linux.md" >}}).


## Installation {#installation}

```bash
sudo pacman -S --needed base-devel
git clone https://aur.archlinux.org/paru.git
cd paru
makepkg -si
```


## --overwrite install conflicting package {#overwrite-install-conflicting-package}

```bash
paru -S dockerfile-language-server-bin --overwrite '*'
paru -Syu --overwrite '*'
```
