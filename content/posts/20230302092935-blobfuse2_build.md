Build the binaries from source code


## Clone the repository {#clone-the-repository}

```bash
git clone https://github.com/Azure/azure-storage-fuse/
cd ./azure-storage-fuse
git checkout main
```


## Build BlobFuse2 {#build-blobfuse2}

```bash
go get
go build -tags=fuse3
```

You could move to [Configure BlobFuse2]({{< relref "20221221164200-blobfuse.md#configure-blobfuse2" >}})
