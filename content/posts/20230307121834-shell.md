## Find out your current shell name {#find-out-your-current-shell-name}

```bash
printf "My current shell - %s\n" "$SHELL"
```


## To list all installed shells, run: {#to-list-all-installed-shells-run}

```bash
chsh -l
```


## And to set one as default for your user do: {#and-to-set-one-as-default-for-your-user-do}

```bash
chsh -s full-path-to-shell
```
