## Definition {#definition}

Virtual services and [Destination rules]({{< relref "destination_rules.md" >}}) are the essential building blocks of Istio’s traffic routing functionality. A virtual service could configure how requests are routed to a service within an Istio service mesh. Each virtual service consists of a set of routing rules. Letting Istio match each request to the virtual service to a specific real destination within the mesh.
