LightDM is a cross-desktop [display manager]({{< relref "20230729224458-display_manager.md" >}}). Its key features are:

-   Cross-desktop - supports different desktop technologies.
-   Supports different display technologies ([Xorg/X11]({{< relref "20230721000322-xorg.md" >}}), Mir, [Wayland]({{< relref "20230721000055-wayland.md" >}}) ...).
-   Lightweight - low memory usage and high performance.
-   Supports guest sessions.
-   Supports remote login (incoming - XDMCP, VNC, outgoing - XDMCP, PAM).
-   Comprehensive test suite.
-   Low code complexity.
