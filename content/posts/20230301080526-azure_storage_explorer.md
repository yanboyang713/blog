Free tool to conveniently manage your Azure cloud storage resources from your desktop.

Upload, download, and manage [Azure Blob]({{< relref "20230104143013-azure_blob.md" >}}) , files, queues, and tables, as well as [Azure Data Lake]({{< relref "20230104141434-azure_data_lake.md" >}}) Storage entities and Azure managed disks. Configure storage permissions and access controls, tiers, and rules.


## Installation {#installation}


### Pre-required {#pre-required}

-   [GNOME Keyring]({{< relref "20230301084729-gnome_keyring.md" >}})


### Install {#install}

```bash
paru -S storageexplorer
```
