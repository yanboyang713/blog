MKTXP is a [Prometheus]({{< relref "20230602142910-prometheus.md" >}}) Exporter for [Mikrotik]({{< relref "20230226101927-mikrotik.md" >}}) [RouterOS]({{< relref "20230417083431-routeros.md" >}}) devices.

It gathers and exports a rich set of metrics across multiple routers, all easily configurable via built-in CLI interface.

While simple to use, MKTXP supports advanced features such as automatic IP address resolution with both local &amp; remote DHCP servers, concurrent exports across multiple router devices, configurable data processing &amp; transformations, etc.
