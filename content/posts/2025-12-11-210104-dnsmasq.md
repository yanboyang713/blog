## [Proxmox VE (PVE)]({{< relref "20230228043925-proxmox_ve.md" >}}) {#proxmox-ve--pve----20230228043925-proxmox-ve-dot-md}

The DHCP integration into the built-in PVE IP Address Management stack currently uses dnsmasq for giving out DHCP leases. Does not support [EVPN on Proxmox SDN]({{< relref "2025-09-28-131926-setting_up_evpn_on_proxmox_sdn.md" >}}).

To use that feature you need to install the dnsmasq package on every node:

```bash
apt update
apt install dnsmasq
# disable default instance
systemctl disable --now dnsmasq
```
