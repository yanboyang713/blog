## Definition of a REST API {#definition-of-a-rest-api}

Let's define the APIs that we will use in our microservice infrastructure using the REST methodology. In this example, our microservices will have minimal APIs for demonstration purposes; real microservices might not be quite so "micro". Let's explore the REST specifications of the [microservices]({{< relref "20230220225947-micro_service.md" >}}) of our application. We will start by looking at a microservice for user registration and go through every part of the application.
