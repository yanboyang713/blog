## Request a new IP address from DHCP server {#request-a-new-ip-address-from-dhcp-server}


### To release the current IP address: {#to-release-the-current-ip-address}

```bash
sudo dhclient -r
```


### To obtain a fresh lease: {#to-obtain-a-fresh-lease}

```bash
sudo dhclient
```
